# Kuluseuranta

**Ilmainen kulujen seuranta ja budjetointi kotiin ja yritykseen.**

[Verkkosivu](https://www.kuluseuranta.com) · [Avaa sovellus](https://app.kuluseuranta.com) · [Kokeile ilman tunnusta](https://app.kuluseuranta.com/kokeile) · [Mitä uutta](https://www.kuluseuranta.com/mita-uutta)

</div>

---

Kuluseuranta tallentaa maksusi automaattisesti puhelimesta, näyttää kulutuksen kaavioina ja seuraa kuukausibudjettia kategorioittain. Käsin kirjaamista ei tarvita. Sovellus ei ole pankki- tai maksusovellus: se lukee jo tehdyt maksuilmoitukset ja tallentaa ne omalle tilillesi.

## Ominaisuudet

- **Automaattinen tallennus.** iPhonella Apple-automaatio (Pikakomennot) tallentaa Apple Wallet -maksut, Androidilla Tasker tai MacroDroid.
- **Kaaviot.** Kulutus päivittäin, kategorioittain ja kuukausitrendinä.
- **Budjetit.** Kategoriakohtaiset kuukausibudjetit, joiden tilanne päivittyy reaaliajassa.
- **Yritystili.** ALV-erittely, kustannuspaikat, kuitit (kuva tai PDF), tiimi kuudella roolilla, kulujen hyväksyntä ja kuukauden vienti kirjanpitoon.
- **Selainlaajennus.** Nopea pääsy kuluihin selaimesta.
- **Tietosuoja.** Tiedot säilytetään EU:ssa, eikä niitä myydä tai jaeta kolmansille osapuolille.
- **Maksuton.** Kaikki ominaisuudet ovat ilmaisia. Ylläpitoa voi halutessaan [tukea](https://www.kuluseuranta.com/tue).

## Tekniikka

- **Sovellus:** staattinen PWA (HTML, CSS, JavaScript), Cloudflare Pages
- **Taustapalvelu:** Cloudflare Workers, D1-tietokanta ja R2-tallennus EU-jurisdiktiossa
- **Selainlaajennus:** Manifest V3 (Chrome, Edge, Firefox)
